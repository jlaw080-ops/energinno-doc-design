# 에너지노 일반 문서 디자인 시스템

주식회사 에너지노(ENERGINNO)의 대외·대내 **일반 문서**(기획안, 제안서, 검토서, 보고서) 표준. 2026년 9월 「신재생에너지 통합 관리 시스템 신규 개발 기획안」에서 확립한 규칙을 추출해 정리했다.

적용 대상은 인쇄·PDF 배포를 전제로 하는 A4 세로 문서다. 슬라이드, 웹 화면, 마케팅물은 대상이 아니다.

출처: 이 프로젝트의 `신재생통합관리시스템_신규개발기획안_v3.dc.html` (원본 문서), 사내 제공 CI 파일 3종.

## 인덱스

- `styles.css` — 토큰 진입점. 소비하는 문서는 이 파일 하나만 연결한다.
- `tokens/colors.css` `tokens/typography.css` `tokens/layout.css` — 색·활자·지면 토큰
- `guidelines/*.html` — 파운데이션 카드 (Type / Colors / Spacing / Document / Brand)
- `template/index.html` — A4 표지 + 본문 1면 템플릿. **새 문서는 이 구조를 복제해서 시작한다.**
- `template/doc-page.js` — 지면 컴포넌트(A4 고정 페이지, 인쇄 규격 담당)
- `assets/energinno-logo.png` — 가로형 CI (2089×547, 투명 배경)
- `assets/energinno-symbol.png` — 심볼 단독
- `SKILL.md` — 외부 에이전트용 진입 문서

## CONTENT FUNDAMENTALS

**문체.** 격식체 3인칭. 자사를 가리킬 때는 "자사" 또는 "에너지노"를 쓰고 "우리"는 쓰지 않는다. 서술 종결은 '~한다' 체(개조식 문서체)이며 '~합니다'는 쓰지 않는다. 상대 회사는 정식 상호("주식회사 해밀")로 처음 한 번, 이후 약칭("해밀")을 쓴다.

**서술 방식.** 사실과 합의 사항만 적는다. 의의·시사점·전망 같은 논평을 덧붙이지 않는다. 미확정 사항은 숨기지 않고 "0단계에서 확정한다", "해밀과 확인이 필요하다"처럼 확정 시점과 주체를 함께 적는다.

**개조식 우선.** 문단 서술보다 목록이 기본이다. 목록 기호는 1단계 `- `, 2단계 `· `까지만 쓰고 3단계는 만들지 않는다. 한 항목은 두 문장을 넘기지 않는다.

**표제 체계.** 장은 `1. 시스템 컨셉`, 절은 `가. 개요`. 로마자·괄호 번호는 쓰지 않는다.

**강조.** 굵게(`font-weight:700`, `color:#1a1a1a`)만 사용한다. 밑줄·이탤릭·색상 강조·형광 배경은 쓰지 않는다. 한 문단에 강조는 한 곳까지.

**용어.** 약어는 첫 등장에서 풀어 쓴다("MQTT(경량 IoT 통신 규약)"). 외래어는 국문 표기를 우선하되 규격명·제품명은 원문 그대로("REMS", "RTU", "ESS").

**날짜·기간.** 절대 날짜는 `2026. 09. 04.` 형식(마침표 뒤 한 칸). 일정은 착수 기준 상대 개월 `M+3 ~ M+7`.

**이모지는 쓰지 않는다.** 특수문자는 `※`(각주 표제), `→`(흐름), `·`(병렬)만 허용한다.

## VISUAL FOUNDATIONS

**기조.** 무채색 인쇄 문서. 컬러는 CI 로고에만 허용하고 본문·표·도해는 검정·회색·흰색으로만 구성한다. 흑백 출력에서도 정보 손실이 없어야 한다.

**지면.** A4 세로 고정. 여백은 Word 기본값(위 30mm, 좌·우·아래 25.4mm). 지면은 `.page` 섹션 하나가 한 면이며, 내용이 넘치면 잘린다 — 면을 나눌 때 반드시 넘침을 확인한다. 표지에는 머리말·꼬리말을 두지 않는다.

**면 구성 순서.** ① 표지 ② 목차 ③ 본문. 각 장(`1.`, `2.`…)은 반드시 새 면에서 시작한다. 절(`가.`, `나.`)은 면을 이어서 쓴다.

**표지.** 상단에 굵은 가로선(2.5px) — 문서 종류(9.5pt, 자간 5pt, 낱자 띄어쓰기) — 제목(26pt, weight 800) — 가는 가로선(1px). 문서정보표는 세로 61~76% 구간(하단 3분의 1). CI는 지면 맨 아래 가운데, 폭 52mm.

**머리말·꼬리말.** 머리말은 왼쪽에 문서명(8.5pt, `#6b6b6b`, 자간 0.2pt), 오른쪽에 가로형 CI(높이 8mm), 아래로 1px `#c9c9c9` 선. 본문은 머리말에서 8mm 띄우고 시작한다. 꼬리말은 쪽번호 `- 1 -`만 가운데(8.5pt, `#8a8a8a`), 지면 하단에서 12.7mm. **회사명은 머리말 CI 한 곳에만 표기한다.**

**활자.** 맑은 고딕 → Apple SD Gothic Neo → NanumSquareNeo 순의 고딕 단일 계열. 세리프는 쓰지 않는다. 크기는 pt로 지정한다(표지 26 / 목차 13·11 / 장 14 / 절 11 / 본문 10.5 / 각주 10 / 표 9.5 / 캡션 9 / 머리말 8.5). 행간은 본문 1.7, 표 1.5.

**표.** 전체 격자선 1px `#a6a6a6`. 머리행은 `#ececec` 배경, 굵게, 가운데 정렬. 셀 여백 5×7px. 숫자·구분값은 가운데, 서술은 왼쪽 정렬. 열 너비는 mm로 고정해 쪽마다 흔들리지 않게 한다. 얼룩무늬(zebra)·세로선 생략 스타일은 쓰지 않는다.

**도해.** 인라인 SVG로 그리고 `viewBox`로 지면 폭에 맞춘다. 상자는 흰색 또는 `#f2f2f2`·`#e4e4e4` 채움에 `#8c8c8c`~`#4a4a4a` 테두리 1~1.2px, 모서리는 각지게. 화살표는 `#4a4a4a` 1.3~1.8px에 삼각 마커. 도해 안 글자는 12pt 이상(지면 기준)으로 두고, 줄바꿈이 생기면 문구를 줄인다. 캡션은 `[그림 n] 제목` 형식으로 도해 아래 가운데, 9pt `#6b6b6b`.

**각주 박스.** `#f7f7f7` 배경에 1px `#a6a6a6` 테두리, 여백 10×14px. 표제는 `※`로 시작하고 굵게, 본문은 `#3d3d3d` 10pt.

**목차.** 1px 테두리 박스 안에 `목 차`(13pt, 자간 4pt, 가운데) — 항목 11pt. 번호 칸 폭은 2em, 항목과 쪽번호 사이는 점선(`1px dotted #b0b0b0`, 3px 위로 보정).

**금지 요소.** 모서리 라운딩, 그림자, 그러데이션, 배경 이미지, 애니메이션, 좌측 컬러 보더 카드, 아이콘 장식. 문서에는 상호작용이 없으므로 hover·press 상태도 정의하지 않는다.

## ICONOGRAPHY

아이콘을 쓰지 않는다. 정보는 표·도해·번호 체계로 전달한다. 도형이 필요하면 SVG 안에서 사각형·직선·삼각 화살표 마커만 사용한다.

브랜드 마크는 제공받은 두 파일만 쓴다. 가로형 CI(`assets/energinno-logo.png`)는 표지 52mm, 머리말 8mm. 태그라인("에너지를 혁신하다. 에너지노")이 들어 있어 **높이 8mm 미만으로 줄이지 않는다** — 그 아래에서는 태그라인이 뭉개진다. 더 작게 넣어야 하면 심볼 단독(`assets/energinno-symbol.png`)을 쓴다. 로고 색은 변형하지 않는다.

## 의도적 추가

- **문서 템플릿(`template/`)** — 원본 문서 한 건에서 반복 가능한 뼈대만 남긴 것. 원본에 없던 구성 요소는 넣지 않았다.

## 미확인 사항

- 사내 표준 서체 규정이 별도로 있는지 확인하지 못했다. 현재는 원본 문서가 쓰던 시스템 고딕(맑은 고딕 계열)을 그대로 승계했다.
- CI 사용 규정집(최소 여백, 최소 크기, 흑백 버전)을 제공받지 못했다. 위 최소 크기 8mm는 원본 문서 검수에서 얻은 실측 기준이다.
